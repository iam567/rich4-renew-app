# 26 附录：挑戰任務清單（v2，2026-11-02）

[挑戰模式](26-challenge-mode.md) 用的任务。**通用库 81 个**（§1，每张图都能抽）＋每张地图最多 20 个**本图任务**（§2–§16，删过一些）。每局把两种混在一起随机抽，抽到满分合计正好 120 颗星为止，先拿到 100 颗星的人赢（26 §2）。

- 门槛（★／★★／★★★）都是提案，模拟（26 §0）之后再调；太难或太容易的会换掉。
- **三种拿星的方式**（用户 2026-11-02：「有些任務完成一個就能拿 3 顆星，有些要完成 1、3、5 次」）：
  - **一次就 ★★★**：很难碰上的事，做到一次就拿满三颗星（表里写「一次就 ★★★」）。
  - **一次就 ★**：做到一次拿 1 颗星，这个任务最多 1 颗（用户在筛选器里定的，例 G05、G09、G14）。
  - **次数**：做到几次给几颗星（多半 1／3／5 次，也有按天数、金额、个数的）。
  - **进度**：「地段」「设施」「董事長」和「几段／几块／几家」这种，越做越多、一档一档升星。
- 「地段」「设施」「董事長」型的门槛见 26 §3：地段 ＝ 整段归你／整段 3 级／整段 5 级；设施 ＝ 盖了规定的设施／3 级／5 级；董事長 ＝ 连续 30／90／180 天。
- **全场一起的任务人人有份**（G03 醫院滿床、G04 牢房客滿、G71 全員同格、Z16 行星連珠、W04 華山論劍）：那一刻在场的每个玩家（真人、电脑）都拿到，不算给促成的人（用户 2026-11-02：「人人有份吧」）。
- 「停过／经过」：停过 ＝ 这一步走完停在那里；经过 ＝ 路过也算。路段 ＝ 同名的小地旁边的路格。
- 名字是游戏里显示的（繁体）；条件写法是给开发看的。
- 各图的格子、地名、企业照地图资料（`game/public/assets/maps/*.json`）；本图专属的规则见 21（歌舞伎町）、24（激情歲月）。

### 0.1 删任务的规律（用户在前六张图删的，2026-11-02 归纳）

- 只要「买齐某一条路段、盖到几级」的单条地段任务（名古屋、好萊塢、少林寺、蘇州、魔羯座區…）。
- 两条路段或「路段＋大型用地」绑在一起升星的（日本海、黑白兩道、汽車城、大理段氏）。
- 只要「拥有／盖好某块大型用地」的（雙城廣州、天秤座區）。
- 太长的「全部路段都停过」（行走江湖 16 段）；和通用任务重复的。
- 留下的：「几段里拥有几段」的路段组合、有事件发生的设施任务（有人住满 4 天、转出 ×6）、董事长、地图特色玩法。
