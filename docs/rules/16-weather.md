# 16 每日天气（重制版新增）

> 这是**重制版自己的新功能**，原版没有天气。纯画面和声音，**不影响任何规则**：不用规则的 rand()，不进存档，电脑的决定、过路费、事件都和关掉天气时一样。
> 例外（重制版大富豪模式，18 号文档）：几条地方新闻、命运只在某种天气的日子发生（例如札幌下雪天的「屋顶积雪滑落」、冲绳颱風天的「班机停飞」）。它们读的是同一个纯函数 `weatherOf(种子, 地图, 日期)`——不碰随机流、不受天气设置影响；天气本身照样只是画面。普通模式没有任何规则读天气。
> 代码：`game/src/ui/climate.ts`（气候表和出处）、`game/src/ui/weather.ts`（每天的天气、设置、日历图标）、`game/src/ui/weather-fx.ts`（地图上的画面和声音、户外小游戏的点缀），
> `board-view.ts` 里只加了一个钩子 `overWorld`。测试 `game/src/ui/weather.test.ts`。

## 1. 规则

- **七种天气**：晴、多雲、雨、雷雨、雪、霧、颱風（颱風只在沖繩、九州、台灣等有颱風季的地方出现，而且很少）。
- **每天一种**，由「游戏种子 + 地图 + 日期」算出（`weatherOf(seed, mapId, date)`）：同一局、同一天永远是同一种天气；读档、重放、日历、地图、小游戏看到的都一样。
  用自己的散列（murmur3 混合），**不碰规则的 `Rng`**，所以开关天气、看不看天气，整局完全一样（测试逐事件比较）。
- **存档不加任何东西**：天气是日期的函数。时光机退回一天，天气也回到那天的。旧存档不用迁移。
- **连续天气**：每天有 35% 的机会沿用昨天的天气种类（连日雨、连日雪），否则按当月机率重抽。这样做不改变每个月的长期比例（测试验证误差 < 4%）。
  沿用的种类今天不可能出现时（例如四月的札幌延续到五月的雪），当天重抽。
- **哪些地图有天气**：台灣 (0)、中國大陸 (1)、日本 (2)、美國 (3)、東京 (100)、大阪 (101)、札幌 (102)、九州 (103)、沖繩 (104)，以及所有工坊地图（温和的温带气候）。
  原版四张主题地图（4 星座、5 武俠、6 恐龍、7 城市主題）是幻想世界，**没有天气**，日历也不显示天气图标。
- **强度**：雨分小雨到大雨（按该月「≥10 mm 日数 / ≥1 mm 日数」的比例决定大雨的机会），雪分小雪到大雪（札幌这类真正积雪的地方大雪更多），雷雨和颱風都是强的。
- **风向**：每天一个风向（世界坐标），雨的斜度和云影的飘移都跟着它，所以转动地图时方向一致。

## 2. 每日机率怎么来

气候表（`climate.ts`）每个月 7 个数，单位都是**每月天数**：降水日（≥1 mm，含雪）、大雨日（≥10 mm）、雷日、雪日、雾日、阴天日（云量 ≥ 8.5）、颱風日。
`monthOdds()` 把它们换成当天的机率：

1. 颱風日、雪日先拿走；
2. 雷雨 = 雷日 ×（1 − 雪日占降水日的比例）− 颱風日 × 0.5（冬天下雪的地方，雷是雪雷，算雪）；
3. 雨 = 降水日 − 雪 − 雷雨 − 颱風（不小于 0）；
4. 雾 = 雾日；以上合计最多占当月 95%；
5. 多雲 = 阴天日 − 0.8 × 降水日（阴天大多是下雨天，已经算过），最多占剩下日子的 85%；
6. 其余是**晴**（包括晴时多云：晴天也会有几片云影飘过）。

换算：

- 気象庁「雪日数」包括只飘几片雪的日子，所以雪日 =（雪日数 + 降雪 ≥1 cm 日数）÷ 2；霧日数只算能见度 < 1 km，游戏里的「霧」也包括薄雾，所以 × 2。
- 颱風日 = 気象庁「台風の平年値」各月接近数（1991–2020）× 比例：沖繩 0.8、九州（北部、南部平均）0.6、東京和大阪 0.25（本土）、札幌 0.08；日本图用本土和沖繩的加权。
- 只有 ≥0.1 mm 降水日的地方（中国、台湾）× 0.72 换成 ≥1 mm；NOAA ≥0.01 in × 0.85。大雨日 = 降水日 × 0.35。
- 只有日照百分比 s 的地方：阴天日比例 = 0.17 + 1.55 ×（0.62 − s），夹在 0.03…0.85（用東京对齐：一月日照 62% ↔ 阴天 17%，六月 29% ↔ 68%）。

原始数字的抓取和换算脚本不进仓库（一次性），换算后的表就是 `climate.ts`。

## 5. 画面

两层，照顾 WebKit 可能用 CPU 画 canvas 的情况：

- **清晰的东西画在地图 canvas 上**（`BoardView.overWorld`，人物和建筑之后、点选光圈和炸弹数字之前）：雨丝（三层深度，一层一条 path）、落地的小水圈、雪花（预先画好的三种大小的贴图）、闪电。
  全部用固定大小的 typed array 当对象池（雨 420、雪 340、水圈 56），每帧不建新对象；数量按画面面积和强度决定（874×402 的画面大雨约 300 条）。
  雨和雪是画面上的粒子，地图卷动时跟着地面移动（相机位移补偿），转动视角时不跟（重新落下）。
- **柔和的东西画在 1/4 解析度的小 canvas 上**，由浏览器合成时放大盖在地图上（`z-index: 1`，在 GO、讯息框、对话框之下）：整体色调、晴天左上的暖光、雨天上方的湿亮反光、云影、雾团、闪电的闪光。
  云影和雾团在**世界坐标**里（跟着地图转动、卷动，形状按地面压扁 K = 0.707），随风飘，飘出视野就从上风处补回。
- **不碰地面缓存**：天气层画在缓存的地面之上，从不让 `GroundCache` 重画。
- **各天气的样子**：
  - 晴：淡暖色 + 左上暖光 + 2–4 片云影慢慢飘过。
  - 多雲：灰蓝色调 + 4–7 片云影。
  - 雨：偏蓝变暗（湿地面）+ 上方淡淡反光 + 雨丝 + 水圈；斜度随风。
  - 雷雨：更暗 + 大雨 + 每分钟 5–9 次闪光（近的有一道闪电），隔 0.25–2.5 秒雷声。
  - 雪：冷色调 + 飘落摇摆的雪花。**札幌（白色地面）**的雪花是蓝灰边、带淡淡影子，色调也稍暗，雪花在白地上看得清。
  - 霧：淡白色调 + 呼吸般浓淡变化的雾团，格子仍然看得见。
  - 颱風：最暗 + 横斜的暴雨 + 快速掠过的云影 + 强风声 + 偶尔闪电。
- **换日**：所有数值用约 3 秒平滑过渡到新的一天。
- **被全屏画面盖住时暂停**（商店、银行柜台和 ATM、分红、黑市、存读档、股市、各特殊地点画面；拉霸和转盘半透明，不算），天气声音降到 30%（像在室内）。
- **户外小游戏**：射氣球、喜從天降是天空背景，当天下雨、雷雨、颱風、雪、雾时，画面上加一层很淡的雨丝或雪花（640×480 设计空间里一块半解析度 canvas，粒子少、半透明，不挡游戏）。企鹅挖宝和其他室内画面不加。

## 6. 声音

全部用 Web Audio 当场合成（不下载文件），走「音效」通道：跟音效音量和静音，音效关掉时不发声也不运算。

- 雨：一段 2 秒的粉红噪声循环，高通 420 Hz + 低通 2.2–6.4 kHz（雨越大越亮、越响）。
- 风（雪、颱風、雷雨，多雲和雾很轻）：同一段噪声经过被慢速振荡器扫动的带通滤波器，音量也缓慢起伏。
- 雷：闪光后 0.25–2.5 秒，一声噪声经过从高到 110 Hz 下降的低通滤波器，音量先爆后滚动衰减 2.6–4.2 秒；近的更响更脆。
- 淡入淡出（时间常数约 0.5–0.8 秒）；没有声音时 2.5 秒后把声源整个停掉。
- 原版 Effect.mkf 没有雨声或雷声；新闻「颱風」的 Effect#89 只有 1.3 秒，不适合当循环风声，所以没用。

## 7. 界面

- **日历**：日视图在大日期右边、月视图在年份下面，一个小的玩具风格图标（SVG：太阳、云、雨滴、闪电、雪花、雾、颱風漩涡）和白底名字（晴、多雲……）。主题地图和关掉天气时不显示。
- **系统窗口**一行「天氣」：开 / 只有畫面 / 關；标题画面「設定」同样一行。存在 `localStorage` 的 `rich4.weather`（0 开、1 只有画面、2 关；默认开），对所有游戏有效。

## 8. 效能

测法：Chrome 模拟手机（DPR 3），CPU 降速 4 倍，每种天气强度 1，各测 3 秒静止和约 4 秒镜头来回移动，记录 rAF 间隔和 `BoardView.draw` 的耗时。

| 画面 | 关掉天气 | 晴 / 多雲 / 霧 | 雨 / 雷雨 / 颱風 | 雪 |
|---|---|---|---|---|
| 東京 874×402 | 60 fps，draw 中位数 1.5 ms（p95 2.7–3.5） | 59.3–60 fps，1.4–2.0 ms | 59.7–60 fps，1.6–1.8 ms | 60 fps，1.7 ms |
| 札幌 402×874 | 60 fps，1.3–1.4 ms | 60 fps，1.3–1.5 ms | 59.5–60 fps，1.4 ms | 60 fps，1.5–1.7 ms |

天气每帧多 0.1–0.4 ms。软件 canvas（`--disable-gpu`）下关掉天气本来就只有 30–39 fps，开天气 30–46 fps，差别在噪声范围内（瓶颈是软件合成，不是天气的绘制）。

## 9. 测试

`game/src/ui/weather.test.ts`：

- 每个气候每个月的机率合计为 1、都不小于 0；
- 同样的种子、地图、日期 → 同样的天气；不同种子 → 不同的序列；
- 主题地图 4–7 没有天气，工坊地图是温带；
- 气候：札幌一月雪 ≥ 40%、七月 0；沖繩任何月份都不下雪，八月颱風 2–12%；東京一月晴 > 60%、雪 < 15%，六月雨 > 30%；九州七月雷雨远多于東京一月；台灣夏天不下雪；
- 连续天气不改变各月比例（与 `monthOdds` 相差 < 4%），而且雨天之后下雨的机会明显高于平均；
- **与规则无关**：同一局电脑对战 150 天，每一步都去读天气和完全不读，事件逐条相同，最后的现金、存款和规则随机数状态也相同。
