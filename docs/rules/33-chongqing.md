# 33 重慶：三層錯層地圖

remake 地圖 109。中國大富豪模式的山城，也先做成單機經典模式能玩的一張圖。設計是用戶 2026-11-08/09 定的，原型在 `rich4-redraw-company/chongqing/prototype-b.html`。

## 1 三層

三塊板像 Photoshop 圖層一樣錯開疊著，上層蓋住下層的一部分：

| 層 | 名字 | 位置 | 格子（用戶要的） |
|---|---|---|---|
| 1 | 江邊 | 最低，在後右，下面是兩江 | 90～100（含公路 12 格） |
| 2 | 城區 | 中間 | 約 80 |
| 3 | 山頂 | 最高，在前左 | 約 60 |

- 三層共用一張地圖、一個座標系。每格、每塊地屬於哪一層，記在地圖 JSON 的 `levels` 段（`editor/build_chongqing.py`）。
- 看得見什麼（用戶 2026-11-09 改：「一層一層地圖顯示…點擊哪一層就顯示哪一層」）：
  - 一次只看一層：這一層清楚，上面的層完全不畫；下面的層和背景虛化（越下面越糊、越暗），看得出縱深。
    看一層時背景虛化；看二層時一層和背景虛化；看三層時二層、一層和背景虛化。手機的畫布沒有模糊濾鏡，靠縮小到 1/4 再到 1/10 再放大來糊（用戶：「在手機上看下層的模糊效果還是不夠強」）。
  - 小地圖右上角有「一層 / 二層 / 三層」三個按鈕，點哪層就看哪層；小地圖也只畫到那一層，下面的層壓暗。
  - 平時鏡頭跟著誰，就看誰所在的那一層（輪到下一個人、或他換了層，就自動跟過去）；手動點的層一直留到那時。
  - 鏡頭被帶去別處時（有人說話、進監獄、住院、飛彈落點、蓋房、怪獸…），那個地方是哪層就切到哪層；鏡頭回到跟人時再回到那人的層（用戶 2026-11-10：「我在一層的時候有玩家進監獄了，他在一個空的地方出對話框…不會把攝像機切到對應的層數去」）。地點的層看離它最近（40 px 內）的格子、地或建築；在公路上不換層。
  - 飛彈選落點時，提示條上有「一層・N / 二層・N / 三層・N」按鈕（N = 那層能打的位置數，公路的算每一層），點哪層就看哪層；只有正在看的那層能點（上面的層沒畫出來，不能點到看不見的東西）。看的那層沒有能打的位置時，自動換到第一個有的層。選完回到自己那層（用戶 2026-11-10：「飛彈我沒辦法選擇幾層的人去放，只能在同一層去放」）。
  - 公路（高架橋）算一層的東西。
  - 畫面旁邊一直標著畫面上那層「第 X 層」，不加「你在」，輪到誰都一樣（用戶 2026-11-09：「別加啥你在第幾層這種文字了，就直接說第幾層就行了，不管我還是電腦都適用」）。
- 整張圖是**夜晚的重慶**，沒有陽光陰影的問題。被上層壓住的地方畫成有頂的街：騎樓、防空洞火鍋、地下商場，亮著燈。
- 地：小地少、大型用地多（用戶：「小地塊可以減少，大地塊可以增加」「再加到 20 塊」），大型用地 20 塊。
- 地塊的方向（用戶 2026-11-09：「在這個方塊裡面是正的，別放斜了」「大型用地…別整這麼斜」）：
  - 每塊地順著旁邊的路轉，但只轉 22.5° 的整數倍，跟路最多差 11.25°；
  - 房子永遠正正地站在自己那塊地上：每棟房子有兩套 8 個方向的圖，一套正的，一套轉 22.5°（`-h`），按地的方向選；
  - 在橫平的路邊，地是正的長方形或左右對稱的菱形，不會斜著。
- 每層的邊不是素框（用戶 2026-11-09：「圍上高樓或山…立交…穿山輕軌，純邊框多少有點醜」）：邊下面掛一圈側牆，一層是洪崖洞吊腳樓，二層是高樓、立交和李子壩穿樓輕軌，三層是山崖、竹林、亭子和纜車；牆要夠高才看得出立體（用戶：「邊緣有點太窄…看不出立體感」，一 / 二 / 三層 150 / 200 / 250 px），下半截隱進夜色裡（圖 remake/chongqing/wall-1…3.webp，`chongqing_ground.py walls`）。
- 地面做舊（用戶 2026-11-09：「路…不太平滑…倒挺符合重慶感覺，索性把地表做的再破爛一點」）：三層的圖重畫成老重慶的舊街，路面裂縫、補丁、坑窪積水，鋪地殘缺、長青苔，佈局不動（`chongqing_ground.py worn-prep`，-r4；用戶「還能再破爛一些麼」再來一遍 `worn2-prep`，-r5）。
- 地塊不壓路、不重疊、不被事件圓盤蓋住、離自己的格子最近（用戶 2026-11-09：「這塊地為啥塞醫院裡去了？你好好檢查一下每個格子的對應情況」）：每塊地連框在內離行車道至少半條路寬、離事件圓盤（約 52 px 半徑）夠遠、彼此隔 3 px、在自己這層裡；離自己的格子比離任何別的格子都近，也不太遠。違反的地在原位四周找最近的合格位置（`build_chongqing._clear_plots`）；一層 21 號地夾在兩段彎路中間，挪到它那格路的對面。企業用地只按樓的大小算。
- 地塊挪過以後，三層地面照新位置整張重畫（-r6，一開始就畫成舊街）：參考圖裡的地塊畫得比遊戲的地塊小一圈，畫出來的方地都壓在遊戲地塊下面，不會露出雙層方塊（用戶 2026-11-09：「這個位置也偏移了…一塊地一塊地的給我檢查…地塊錯誤的太離譜了」）。合成後逐塊檢查 118 塊地：框外有沒有露出原圖的淺色方塊、有沒有壓路壓圓盤，並逐塊裁圖看過。
- 公路和兩層路口相接的那一格是普通的格子（現在是得30點），算一步：例如二層從卡片走到企鵝挖寶是 4 步（卡片旁一格、橋頭的得30點、再一格、企鵝）。橋面的路鋪過它，它的圓盤在橋面之後再畫一次，不會被蓋住。
- 千廝門大橋橋塔畫成兩倍大（用戶：「怎麼這麼小？」）。
- 地塊嚴絲合縫（用戶 2026-11-09）：遊戲裡每塊空地畫一圈乾淨的粗框，正好蓋住地圖圖片裡地塊的邊（那邊轉過以後是毛的）。原本是金色，用戶嫌「滿屏的黃色描邊太出戲、太跳」，改成街上舊石頭的灰褐色路緣，裡面一條很淡的金線表示能買；有主的地，框和底色是主人的顏色。
- 路面中間的白色虛線**一格一條**（用戶：「白色小條兒，中間有個虛線」「放上幾個小線段來表現出是幾個格…用遙控骰子…不知道該走幾格」）：每條白線就是一格，數白線就知道走幾步；高架橋上也一樣。地圖圖片上不畫圓點。

## 2 換層

- 扶梯和直梯的格子各有自己的事件圓盤（用戶 2026-11-09：「扶梯在哪裡？直梯在哪裡？…找一個事件地標做成扶梯和直梯的樣子，作為踩中的傳送用的地塊」）：扶梯 ESCALATOR（二層 92、三層 170 兩頭），直梯 LIFT（一、二、三層同一個位置，像一根電梯井）。畫成原版圓盤的樣子（map 9201 / 9202，`chongqing_ground.py links`），只有普通圓盤的 0.55 大，因為旁邊的地塊離得近。
- 搭扶梯、直梯時放一個小動畫（用戶：「能不能有一個小動畫…提醒玩家從幾層移動到幾層」）：左邊三層的剖面，頭像從出發那層滑到到達那層，右邊扶梯／直梯的圓盤和「搭直梯　一層 ▲ 三層」，約 2 秒（`ui/screens/cq-link.ts`）。
- 路的寬度在合成地面時校正（用戶：「你不感覺這裡的道路明顯拓寬了嗎？」）：路裡面一律是瀝青，兩邊一道統一的舊石頭路緣，畫寬了溢出來的瀝青用旁邊的石板補掉（`chongqing_ground.true_roads`）。

- 走公路（高架橋，12 格）時一層慢慢糊掉、二層慢慢顯出來，每走一格變一點（用戶 2026-11-09：「移動著慢慢的一層變模糊，二層顯示出來，做出立體感」）；橋和橋上的人一直清楚，畫在二層上面，接上二層的路。橋不再用重畫的圖片（那張圖 8 個方向各自走樣，格子飛到橋外，用戶：「這都飛橋外面了」），改成遊戲照 12 格的位置直接畫：橋面、護欄、一格一條白線、路燈，橋墩往下伸（靠一層 150 px、靠二層 200 px，下截隱掉），橋身只到第一格和最後一格，路面圓頭接進兩層的路（「鏈接處要優化」）。標籤寫「公路」。


**只有正好停在換層格上才換層，路過不算。**

- **扶梯**（三層↔二層，一部，重慶特色）：
  - 停在二層那頭，上三層；
  - 停在三層那頭，下二層。
- **直梯**（一部）：三層在同一個位置各有一格。停上去：
  - 三層→二層；
  - 二層→一層；
  - 一層→三層。

  只能往下一層，或從最底下一口氣上兩層。
- **公路**（二層↔一層）：12 格盤山高架，兩頭都是岔路口，跟一般岔路一樣看箭頭選方向，上下都能走。
  - 路上的格子依序是：點券、空格、點券、空格、小遊戲、空格，重複兩遍。
  - 公路上不能買地。
  - 這 12 格算第一層的，掛在兩塊板外面的江上。
  - 公路是一個 3D 高架橋素材（map/3974）：圓橋墩立在江裡，越往二層越高，有護欄、路燈、中線虛線；桥面高度和格子一致，兩頭接一層、二層的路口（用戶：「這個柱子有點太假了」，原來是平面畫的）。

## 3 版面規則

`editor/chongqing_audit.py` 每層分開查，不同層的格子可以疊在一起，不互相比較：

- 每層格子數；總共最多 255 格；
- 路不交叉；
- 每格都在自己那層的板上；
- 地不壓路、地和地不重疊；
- 事件不相鄰，同種事件至少隔 20 步；
- 換層的路口要露在上層外面：
  - 扶梯的二層那頭不能被三層蓋住；
  - 公路兩頭不能被上層蓋住。

事件種類由 `chongqing_routes.assign_events` 在整張圖上自動排開。公路上的事件按用戶指定的順序放，不算進同種事件相隔的規則。

用戶 2026-11-09 的玩法：
- 停在別人的麻將館，先玩一題，再付租金：
  - 畫面亮出一手 13 張、已經聽牌的牌，問「再摸哪幾張能胡？」；

  - **1、2 級**：點中一張能胡的就算對；

  - 付多少（用戶 2026-11-09：「答對的話就是付一半的租金，答錯的話就是付雙倍租金。僅答對一個的話，就是付正常租金」）：
    - **答對**（1、2 級點中一張；3 級起全部選對、沒多選錯的）：付**一半**租金；
    - **只對一部分**（3 級起，選中了至少一張能胡的，但沒全選對）：付**正常**租金；
    - **答錯**（一張能胡的都沒選中）或超時：付**雙倍**租金；
  - 8 張候選裡除了能胡的那幾張，其餘都是陷阱（看起來像、其實不胡）。
- 房東在任何情況下都不倒給錢。
- 租金照原版過路費的算法算，所有影響過路費的都照算（用戶：「也可以受小財神、大財神…小窮神、大窮神的影響，也可以受物價的影響，也可以受漲價卡什麼的影響」）：物價指數、財神／窮神（加倍、免付）、漲價卡、免費卡等；減半、加倍是在這些都算完以後再算。
- 題目要難（用戶：「不能整那種太簡單的牌…像那種清一色的牌，像 22334455667788999…一眼看上去比較難猜出來，得算好久」）：
  - 出清一色的手牌，一整門混在一起；
  - 程序把每一手算一遍，按上表的等級挑牌型和聽的張數。
