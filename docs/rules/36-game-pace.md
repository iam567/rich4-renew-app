# 36 游戏节奏（慢节奏／原版／快节奏，2026-11-23）

用户 2026-11-23：很多玩家说一局太短。一起看了原因：物价指数（平均资产 ÷ 初始资金，只升不降）把过路费、地价、盖房费一起放大，后期越滚越快；街道四、五级房子的过路费（例如 300/750/2000/4800/10000/18000）踩一次就能让人破产。用户同意做成三档开关，规则是他定的：

> 「慢节奏：物价指数用初始资金×2；可以有破产资产清算——现金存款周转不灵的时候，按2次租金的价格，卖掉所有楼房和空地给银行，股票也卖掉，变成存款存进银行，然后手握存款继续游戏。快节奏：物价指数用初始资金×0.5，房价地价×1.2。」
>
> 「把清算提高到3倍再试试」——然后：「能提高一倍的游戏时长就可以了」（同日）。为了到一倍，慢节奏又加了过路费六折（见下）。
>
> 「快节奏、慢节奏都不能进排行榜，以后所有的改动，只有原版模式和规则下玩的才能进排行榜」

代码：`core/game.ts`（`PACE`、`paceOf`、`paceBoard`、`Game.pace`、`updatePriceIndex`、`paceLiquidate`）、`core/types.ts`（`GameSettings.pace`、`PACE_NAMES`、`PACE_HINTS`）、`core/compat.ts`（`pace`）、`core/ranks.ts`（`notRanked` → `'pace'`）、`tools/party-relay/ranks.mjs`（`badSettings` → `'pace'`）、`ui/main.ts`（新游戏）、`ui/party.ts` `ui/party-net.ts`（派对房间）、`ui/next-game.ts`（下一局）、`ui/ranks.ts`（局后提示）。测试 `core/pace.test.ts`、`core/ranks.test.ts`、`ui/party-rules.test.ts`、`ui/next-game.test.ts`。

## 1 设定

- `settings.pace`：0 慢节奏、2 快节奏；**原版不写这个字段**（1 也当原版），所以以前的存档、回放、测试一律照旧，原版不多抽一次随机数。
- 新游戏：「玩法」（回合制／即时制）下面一行「游戏节奏」：慢节奏／**原版**（默认）／快节奏。原版地图、自制地图、我的地图、即时制都有；**挑战模式（星星局）和大富豪模式没有**（规则不同）。选了慢或快，下面多一行黄字说明：「物价涨得慢・周转不灵可清算资产・不上排行榜」／「物价涨得快・房价地价×1.2・不上排行榜」。
- 新游戏设定要一屏装下（用户 2026-11-23：「設置菜單盡可能要屏幕裝得下，盡可能不要上下滑動，實在實在實在很極端的情況下不行的情況再滑動」）：「开局日期」挪到返回／开始游戏按钮左边，设定栏只放设定。横屏 1920×1080、1400×900、1280×720、800×600、667×375，竖屏 430×932、390×844、360×640、320×568，连折叠屏 360×480，原版／慢／快、回合制／即时制、原版地图／自制地图／我的地图、2／3／4 人都不用滑。竖屏最小缩到 0.5 倍（`NG_MIN_SCALE`），比这还矮的屏幕设定栏才上下滑，按钮固定在下面。
- 派对模式：房间设定「电脑难度」下面一行「游戏节奏」（房主选，`PartyRules.pace`，原版不写），选了慢或快下面有一行说明。房间里有不认识这个设定的旧版手机时（`level` 早于 1.3.0），整局按原版玩（`compat` 的 `pace`，`paceOf`）。
- 「下一局」沿用上一局的游戏节奏。
- 存档：设定跟着存；快节奏改过的地价存在棋盘里，读档不会再乘一次。

## 2 规则

| | 物价指数 | 其他 |
|---|---|---|
| 慢节奏 | 平均资产 ÷（初始资金 × 2），取整，只升不降 | 过路费和大块地收费 × 0.6（`PACE[0].toll`，四舍五入到元）；资产清算（下面） |
| 原版 | 平均资产 ÷ 初始资金（原版） | — |
| 快节奏 | 平均资产 ÷（初始资金 × 0.5），开局第一天就是 2 | 地价、每级盖房费、大块地价格和升级费 × 1.2（四舍五入到十位） |

- 快节奏的 ×1.2 直接改这一局自己的棋盘数字：买地、盖房、升级付的钱都多两成，资产里地产的价值（地价 + 级数 × 每级费用）也跟着多两成，黑市、拍卖、电脑估价都看同一个数。**过路费表不动**（只随物价指数变）。
- 慢节奏的**资产清算**（`paceLiquidate`）：要付钱而现金加存款不够时（原版这里就破产了），不问玩家，电脑和真人都一样：
  1. 股票全部按现价卖掉（派对的杠杆仓位也平掉），钱进存款；
  2. 名下所有小块地和大块地（有房没房都算）卖给银行，每块按**当前租金 × 3**（`LIQUIDATE_RENT`；起初是 2，用户 2026-11-23 改成 3）：小块地是它自己这一级的过路费（空地是 0 级的过路费，连锁店 2000）× 物价指数，大块地是它这一级的收费（没盖的按 1 级的收费）× 物价指数；地变成无主，房子留在地上；
  3. 钱全进存款，从存款里付清欠的钱，手握剩下的存款继续玩；
  4. 卖完还不够才破产；什么都没有可卖就直接破产。
  - 提示：「某某资产清算：卖掉N处房地产和股票，得X元存入银行」（只有地或只有股票时只说那一样）。
  - 派对模式的「破产清算」（追加玩法，半价卖、真人会被问）在慢节奏局里由这条代替。

## 3 排行榜

- 只有原版节奏的局能上榜（`notRanked` 返回 `'pace'`；本来就不能上榜的局先说原来的原因）。赢了慢／快节奏的局会提示「慢节奏对局不计入排行榜（只有原版节奏的对局才能上榜）」。
- 服务器也拒收：`tools/party-relay/ranks.mjs` 的 `badSettings` 看到 `pace` 不是原版就退回（`'pace'`）。**要部署到 relay 才生效**。
