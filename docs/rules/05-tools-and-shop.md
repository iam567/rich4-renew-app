### 0.2 术语与数据位置

- **道具 ID**：代码里一律 1 基（1..13），库存数组下标 = ID-1。`tool_table` 每项 8 字节：`name(+0) max_amount(+4) price(+5) f6(+6) f7(+7)`（`tool.h`、`rich4_tool_table.c`）。
- **玩家结构**：`_rich4_all_players_state`（0x496b68），每人 0x68 字节。本文用到的偏移：
  `+0x08/+0x0A` 像素坐标，`+0x0C` 当前道路节点，`+0x0E` 上一节点，`+0x10` 朝向，`+0x11` 交通方式（0 步行 / 1 机车 / 2 汽车 / 低 2 位为 3 = 工程车，高 6 位为剩余计数），`+0x12` 骰子数，`+0x13` 角色，`+0x15` 控制者（1 = 人类，bit1/bit2 = 电脑，0 = 已出局；bit6 0x40 = “本次被炸伤”临时标志），`+0x16` AI 行为位，`+0x17` AI 性格档（0/1/2），`+0x1C` 现金，`+0x30` 点券（uint16），`+0x32..+0x35` 旅馆/消失/监狱/医院天数，`+0x37` 梦游天数，`+0x40` 身上挂的定时炸弹对象号，`+0x4C` 起 4 个 dword 仇恨值，`+0x64/+0x65` 工程车期间暂存的原交通方式/骰子数。
- **道具库存**：`_rich4_player_tool_amount[15*玩家 + (ID-1)]`（0x49915c，每人 15 字节，只用前 13）。
- **全局道具供应池**：`_rich4_remain_tool_amount[8]`（0x497320），只管 ID 1..8。
- **对象表**：`_rich4_objects_info`（0x496d08），46 个槽 × 0x18 字节：`+0 类型 +1 朝向 +2 所在节点 +4 计时 +5 附着玩家号(1 基)`。
- **道路节点**：`_rich4_map_node_ptr`，每节点 0x28 字节；`+0x20` 旁边地块的实例号（2000..3999 = 住宅用地、4000..5999 = 商业设施、6000..7999 = 商店等），`+0x24` 位域：bit0-7 节点类型，bit8-11 玩家 0..3 占位，bit12-15 特殊角色占位，bit16-23 对象槽号(1 基)，bit30-33 单向限制。
- **价格指数** `_rich4_price_index`（0x4990e8），下文记作 `PI`。
- **特殊角色**（`current_player` 4..7，`_rich4_special_player_names`）：4 小偷、5 强盗、6 流氓、7 间谍【代码确认：`rich4.asm:49886` 起的名字表，Big5 解码】。`current_player == 8` 是机器娃娃专用的虚拟槽。

## 2. 通用机制

### 2.1 持有上限与全局供应池

1. 领取道具 `rich4_receive_tool(p, id)`（0x445a4d，`rich4_tool_utils.c:11-24`）【代码确认】：
   - 若该玩家此道具已有 ≥ 9 个：什么都不做（不领取，也不扣供应池）。
   - 否则若 `id ≤ 8`：供应池为 0 则不领取；否则供应池 -1、库存 +1。
   - `id ≥ 9`：直接库存 +1。
2. 使用后归还 `rich4_after_player_use_tool(p, id)`（0x445aa2，`rich4_tool_utils.c:27-39`）：库存 -1；若 `id ≤ 8` 供应池 +1【代码确认】。
3. **守恒关系**（ID 1..8）：`供应池 + 所有玩家库存 + 地图上的对象 + 正在乘坐的机车/汽车 = 10`。具体：
   - 路障/地雷/定时炸弹被放到地图上时**只扣库存、不还供应池**（`rich4_tool_luzhang.asm:88`、`dilei.asm:88`、`dingshizhadan.asm:88` 直接 `dec`），等对象被移除时才还池（`rich4_objects.asm:158-169`）【代码确认】。
   - 骑上机车/汽车时只扣库存（`rich4_tool_jiche.asm:68`、`qiche.asm:72`），车被毁时才还池（`rich4.asm:6887` `fcn_0040cd07`）；下车/换车则把车放回库存【代码确认】。
4. 新游戏初始化（`rich4_new_game.asm:4052-4139`）【代码确认】：
   - 供应池 = 每种 10。
   - 若开局设定了初始交通工具（`ref_0046cb44` = 0 步行 / 1 机车 / 2 汽车），每位参赛者直接乘坐，并从对应供应池扣 1；骰子数 = 设定值 + 1。
   - 每位参赛者各领取 1 个：机器娃娃(1)、路障(2)、地雷(3)、定时炸弹(4)、遥控骰子(8)、机器工人(9)（按 `rich4_receive_tool` 规则，从供应池扣）。
   - 例：4 人局、开局步行时，供应池剩余为 机器娃娃 6、路障 6、地雷 6、定时炸弹 6、机车 10、汽车 10、飞弹 10、遥控骰子 6。

### 2.5 使用时机与流程

- **人类**：顶部面板的“道具”按钮（`rich4_ui_clicking_top_panel.asm:88` → `_rich4_ui_use_tool_entry` 0x447d97）。道具面板最多显示 13 格（5 列 × 3 行，`csrc/tools_ui.c:fcn_447c6e`），乘坐机车/汽车时另有“下车”按钮（`fcn_00447c00`，`rich4_ui_use_tool.asm:1312`）。
  - 道具函数返回 0 = 本次未生效（取消选择、条件不满足），**不消耗**，重新弹出道具面板；返回非 0 = 结束道具流程（`csrc/tools_ui.c` `do { … } while (ebx == 0)`）【代码确认】。
  - **每打开一次面板只能成功使用 1 件道具**（`rich4_ui_use_tool.asm:1542-1615`：道具函数返回非 0 即退出面板）【代码确认】。
  - 道具面板关闭后执行 `fcn_0040defe`（`rich4_player_utils.asm:1136`）：若回合阶段仍为 0（尚未掷骰/移动）且无暂停标志，就重新启用顶部面板，因此**掷骰前可以反复打开面板、一次一件地使用多个道具**【代码确认】。
  - 若道具已让角色进入移动（遥控骰子、传送自己），本回合的道具阶段结束；若使用后玩家处于旅馆/消失/监狱/医院/梦游/冬眠（如被自己的飞弹炸进医院），置 `0x498ea0 |= 0x80` 自动结束回合【代码确认】。
  - 掷骰（`fcn_0040dd1f` 把阶段设为 1/2）之后不能再用道具【代码确认阶段判断；面板按钮禁用的具体代码未逐行核对 →【推测·待实测】】。
- **电脑**：每回合在“变卖/交易”之后，`rand() & 1` 决定本回合尝试用卡（1）还是用道具（0），二者择一（`rich4.asm:11640-11644`）【代码确认】；道具选择规则见 §10.1。

## 3. 各道具详细规则

### 3.1 机器娃娃（ID 1）

【代码确认】`rich4_tool_jiqiwawa.asm`（`_rich4_use_tool_jiqiwawa`）：
1. 先调用 `rich4_after_player_use_tool(cur, 1)`（库存 -1，供应池 +1）。
2. 把当前玩家的像素坐标、当前节点、上一节点、朝向复制到特殊槽 8（`_rich4_all_special_players_state+64..+73`），记下主人编号；然后 `current_player = 8`，调用 `fcn_0040dd1f` 开始移动。
3. `fcn_0040dd1f` 对 `current_player ≥ 8` 固定 **剩余步数 = 9**（`rich4_player_utils.asm:1110-1114`）。

### 10.2 AI 购物

【代码确认】`rich4_shop.asm:2242-2717`（电脑不生成货架、不用随机数）。设 P = 点券，A = 性格档 `+0x17`（0/1/2，`rich4_ui_ai_settings.asm:652-668, 771`），“厌恶”条件 `f7 - A == 2`（只在 A=0 且 f7=2 时成立）：
1. 卖卡：按**手牌槽位下标**查 `card_table[槽位].f7`（原版缺陷，本应按卡 ID）；0 号槽对应的表项 f7=2，所以 A=0 的电脑只要有卡就会把全部手牌按 90% 卖光；A=1/2 不卖。
2. 卖道具：A=0 时卖光 f7=2 的道具（飞弹、时光机、工程车、核子飞弹）。
3. 若 P < 100：卖掉最便宜的一张卡（并列取第一张）；每种道具只留 1 个，多余卖掉；骑机车时卖掉库存里的全部机车，开汽车时卖掉全部汽车。
4. 预算：P = 0 结束。卡片预算 `Bc = ⌊P/2⌋`，道具预算 `Bt = P - ⌊P/2⌋`。
5. 买卡：对每种卡，按全局剩余量放入候选（价 ≤ Bc 且不厌恶），按价格降序 `qsort`，依次买，买得起（价 ≤ 剩余 Bc）就买，手牌满 15 张停止。同价顺序取决于 qsort 实现【推测·待实测】。**重制改动**（用户 2026-10-19，`REMAKE_AI_ONE_CARD`，普通模式和大富豪模式都一样）：每种卡最多一个候选，即电脑每次进店每种卡最多买一张；原版按剩余张数可以一次买好几张同样的卡。关掉开关就是原版（golden 测试逐位验证）。
6. 买车：未骑机车、库存无机车、`80 < Bt`、供应池有机车 → 买机车，`Bt -= 80`；汽车同理（`150 < Bt`）。注意是严格小于。
7. 其余道具按固定顺序 遥控骰子(8)、路障(2)、飞弹(7)、机器娃娃(1)、定时炸弹(4)、地雷(3)（`ref_004755f0` = {7,1,6,0,3,2}），每种最多 1 个：持有 < 9、不厌恶、价 ≤ Bt、供应池 ≠ 0。

  // stepsLeft 已减 1；=0 表示停下

      const other = lowestOtherPlayerOn(node, p);
      if (other !== null && isInGame(other) && !attachedBomb(other)) transferBomb(bomb, other);

  }
  const obj = objectAt(node);
  if (!obj) return;
  switch (obj.type) {
