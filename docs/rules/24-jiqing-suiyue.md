## 9 声音：大喇叭的广播（用户：「還要加上樣板戲的大喇叭廣播聲」）

### 9.1 版权（研究结果）

- 样板戏的音乐、唱段都是 1960 年代中后期写的，作曲者很多 1970–2000 年代才去世（例如于会泳 1977 年去世），中国《著作权法》对自然人作品保护到**作者死后第 50 年年底**，所以多数样板戏音乐**还在保护期**；而且是集体改编作品，权利链复杂（《沙家浜》《红灯记》都改编自更早的沪剧、电影）。
- 当年的录音：录音制作者权保护 50 年（从首次制作完成算），1970 年代的录音大多刚过或正要过期，但**唱片公司的翻录、修复版本是新的录音**，日本、美国的保护期更长。网上找不到能证明是公有领域、或是自由授权（CC）的样板戏录音。
- 结论：**不用真实的样板戏唱段和旧录音**（不翻录，也不照着谱重新演奏真实的旋律）。

### 9.2 方案（推荐 b）

- (a) 公有领域／自由授权的录音：没找到能核实的，不用。
- **(b) 原创的「样板戏风格」音乐（推荐）**：用 Web Audio 合成（同歌舞伎町的警笛，`audio.ambience()` 的效果总线）：京胡（锯齿波＋带通，滑音）、板鼓、锣、钹的打击乐型（「锣鼓经」那样的节奏型，节奏型本身不是受保护的旋律）、原创的西皮／二黄风格短句（自己编的旋律，不照任何真实唱段）。或者在离线用工具生成原创的乐句录成短的音频（不用 AI 模仿真实唱段）。
- 广播的**开始曲**：原创的 3 秒短号＋钟琴（不是《東方紅》，避免任何旋律疑问）。
- **播音**：调侃的广播稿，用 TTS 生成（普通话的男女播音腔，不模仿任何真实的人），例：「社員同志們，今天的工分已經記好了，請不要再去找記工員」「供銷社到了一批暖水瓶，每戶限購一個，請帶好購貨本」「最新消息：本市自行車突破一百萬輛，請大家注意靠右行駛」「現在開始做第五套廣播體操，預備——起！」（第五套 1971 年推行，口令是自己写的数拍子）。约 20 句。
- **喇叭效果**：每个声源 → 带通 300–3,400 Hz → 轻微失真（waveshaper）→ 120–250 ms 的回声（两三个喇叭之间的延迟）→ 按喇叭在画面上的位置左右声道，离画面中心越远越小越闷（同警笛的写法）。

### 9.3 什么时候、在哪里、多大声

- 声源：两个「廣播喇叭」地标、天安門廣場、四个廣播站格、大学门口（做操时）。只有声源在画面附近（约 900 px 内）才听得到，离开渐弱。
- 节目单：每 60–120 秒一段 15–30 秒的节目（开始曲 → 一句播音 → 一段原创样板戏风格音乐或广播体操口令），段与段之间安静；抽到新闻（廣播站）时播开始曲 1 秒（不管在哪里）。
- 音量：最大 0.12（同警笛、天气雨声的大小，不盖过音乐），走效果音量和静音；对话框、小游戏打开、页面隐藏时静音。
- 设置：「大喇叭廣播」开／关（本图才显示；低记忆体等级照样开，因为是合成的，记忆体很小）。
