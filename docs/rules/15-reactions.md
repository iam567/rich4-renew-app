# 15 角色的反应台词：被卡片、道具、倒霉事件打中时谁说什么

> 适用版本：rich4.exe v3.11（与 `upstream/rich4` 一致）。
> 依据：只用反汇编（`upstream/rich4/asm`）、`rich4.exe` 数据段的字符串（`#NNNN` 语音号）和 Speaking.mkf 语音对照表（`game/src/ui/voices.ts`）。没有运行游戏。
> 路径缩写同 11：`rich4.asm:N`；其它 asm 文件写文件名（省略 `rich4_` 前缀）；`core` = `rich4_player_core_actions.asm`。
> 台词写法同 11：`say(人, 表情, 文本)`，表情 0 普通 / 1 皱眉 / 2 流泪 / 3 大笑。`card[k][id]` = `rich4_card_strings[角色][k][卡号 − 1]`（k：0 使用者、1 对自己用、2 受害者）；`event[s]` = `_rich4_event_strings[角色×27 + s]`。
> 语音号：`card[2][id]` 的语音 = 约翰喬的号码 + 52 × 角色序号（下表写约翰喬的号码和金貝貝的号码）；`event[s]` 的语音 = 1050 + 27 × 角色序号 + s（12 §3.2）。

可信度标签：【代码确认】在反汇编中逐行读到；【代码确认*】读到了调用和参数，个别分支的用途按上下文判断；【推测·待实测】。

## 0. 结论

1. 原版**所有**台词都经过 `_rich4_player_say`（rich4.asm:23534）。把全部 asm 里的调用点（约 110 处）逐个列出后：**被害人的反应台词都是一人一句，没有「所有角色一起吐槽」的循环**。「很多人都在叫苦」的印象来自：每一次付钱、住院、坐牢、被卡片打中，受害人都会说一句；坐牢、住院期间**每回合开头**还有一半机率再叫一次（§3.1）。【代码确认】
2. 重制版之前缺的：卡片受害人台词（均貧、購地、換地、換屋、拍賣、搶奪、陷害、復仇、嫁禍、免費、查稅、同盟，§2）；坐牢、住院中每回合开头的哀叫（§3.1）；过路费被免收时付款人的庆幸（§3.2）；饭店、商场、加油站和企业收费时的付款/收款台词（§3.3）；命运 32、命运 33–36 逃过一劫的台词（§3.4）。另有两处多说了：命运 1（征地）原版没有台词；嫁禍卡的「冤枉啊！」是重制版自编的，原版是受害人的 `card[2][18]`。
3. `_rich4_player_say` 的两条全局规则，重制版都照做（`game/src/ui/map-fx.ts` `line()`）：
   - 说话人在消失（+51）、冬眠（+54）、梦游（+55）中时**不说**。【代码确认】rich4.asm:23548-23556
   - **同一句不连说两次**：函数记住上一句的字符串指针 `0x4762c8`，下一次传进来的是同一个指针就直接返回（rich4.asm:23542-23544，全程序只有这里读写）。重制版按语音号判断（每句有自己的 `#NNNN`）。【代码确认】

## 1. 时机与画法（同 11 §0.5）

镜头先移到说话人（参数不带 0x8000 时），对白云 Data#517.6 + 表情头像 + 文字，播 `#NNNN` 语音，至少 1000 ms，语音长就等语音（12 §3.1）。语音用**音效音量**（cfg+3）；重制版用独立的语音音量，对白云在静音时照样出现。

## 3. 倒霉事件的哀叫

### 3.1 坐牢、住院中的每一回合（`fcn_0040c912`，rich4.asm:6561-6760）【代码确认】

轮到一个不能行动的玩家时（01 §3.3 返回值 0），依次判断，讯息格式化到同一个缓冲（后面的盖掉前面的）：

| 住宿（+50） | — | 「%s住宿中\n\n還剩%d天！」 |

## 4. 重制版的结果框（重制版新增）

原版很多卡片只改数字（侧栏的钱、股价）。重制版在受害人台词之后（查稅卡：在原版讯息框的位置、台词之前）弹出和新闻命运同款的结果框（`screens/event-result.ts`），标题「卡片」+ 卡名，一行一人带头像和金额：

| 卡 | 标题行 | 每行 |
|---|---|---|
| 均富 | 「X使用均富卡：所有人的現金平均分配，每人N元」 | 每人「現金 a → b」与差额 |
| 均貧 | 「X對Y使用均貧卡：兩人現金平分，各得N元」 | 两人的现金变化 |
| 購地 | 「X用購地卡買下Y的某地」 | 买方 −价钱、卖方 +价钱 |
| 換地 / 換屋 | 「X交換了A與B的地主 / 房屋」 | 每块地：原地主 → 新地主 / 原等级 → 新等级 |
| 天使 / 恶魔 | 「X對某路段使用天使卡 / 惡魔卡…」 | 每个地主「n處房屋加蓋一層 / 被夷為平地」 |
| 怪獸 / 拆除 | 「X對Y的某地使用…」 | 「某地的建築 a級 → b級 / 被夷為平地」 |
| 搶奪 | 「X搶走Y的某卡/道具」 | 失去 / 得到 |
| 冬眠 | 「X使用冬眠卡：其他人冬眠5天」 | 每个被冬眠的人 |
| 紅卡 / 黑卡 | 「X對某股使用紅卡！」（原版电脑用卡时的讯息框「對%s使用%s！」） | 顶部红（涨）/ 绿（跌）面板：股名、原价 → 新价、涨跌与百分比、「強制漲停 / 跌停」；每个股东「持有n股，市值增加/減少」与金额；地图上同时播涨跌图（`event-fx.ts` chart） |
| 查稅 | 「X對Y查稅：抽取N元稅金！」 | 付税人 −N、使用者 +N（进存款） |
| 同盟 | 「X與Y結盟：7天內互不收過路費」 | 两人 |

结果框至少 2 秒，点一下关闭（同新闻）。卡片宣告（Data#571+ 卡图）照旧在前。
