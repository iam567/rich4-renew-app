# 32 安卓电视版（Android TV）

用户 2026-11-08：「做一个安卓 TV 版……大家可以用遥控器或者用游戏手柄玩。最好可以一家人用两个、三个、四个游戏手柄玩」；「单独再分出一个 ATV 版本，让人知道我真的是在做」。

## 1 两个安装包，都能在电视上用

- `rich4-<版本>.apk`（手机版）和 `rich4-<版本>-androidtv.apk`（电视版）是同一个游戏，`build.gradle` 的 `phone` / `tv` 两种打包，电视版的名字叫「大富翁4 TV」。
- 两个都能装在电视或电视盒子上：不要求触控屏，带 Android TV 桌面的入口和横幅图（`res/drawable-xhdpi/tv_banner.png`，生图软件画的，`tools/tycoon-art/tv_banner.py`）。
- `npm run package -- apk` 一次打出两个。

## 2 遥控器

- 方向键移动焦点，中间的 OK 键是「确定」（MainActivity 把它当 Enter 交给网页），返回键是「返回」，主页键离开游戏。
- 焦点、按钮提示这些都沿用手柄操作（`ui/pad.ts`，issue #15）。

## 3 一家人 1P～4P，每人一个手柄

- 系统给手柄的编号顺序就是 1 号～4 号手把，第 k 个手把管第 k 个「玩家」座位（新游戏里设成「玩家」的座位，按 1P、2P… 的顺序）。
- 轮到某个玩家选择时（掷骰、买地、用卡……），只有他的手把有用，别人的手把按了不算；选单、电脑的回合、动画，谁的手把都能按。
- 某个玩家没有对应的手把（手把比玩家少），轮到他时任何手把都能按。遥控器和键盘永远都能按。
- 两个手把以上、两个玩家以上时，轮到谁开始掷骰，画面会闪一下「2P 某某 / 请用 2 号手把」。
