# 20 全局统计、结算画面与下一局（重制版新增）

> 范围：整局统计账本（`game/src/core/stats.ts`）记什么、怎么记、怎么存；好事 / 坏事的分类表；结算画面（`game/src/ui/results.ts`）；「下一局」与原版结束流程的对应（`game/src/ui/next-game.ts`）。原版没有这些功能，规则判定一律不受影响。

## 1. 原则

- **只观察，不改规则**：账本读引擎吐出的事件（`GameEvent`），另外在几处没有事件的时刻显式调用 `stats?.x()`（商店买卡买道具、道具成功使用、股票成交、小游戏得分、每日开始、取得城市霸主）。它不抽随机数，也不改任何规则状态。普通模式 13 张地图的逐位指纹测试（`regional-golden.test.ts`）不变；`stats.test.ts` 另外验证有无账本时每一步事件与存档逐位相同（经典与大富豪模式各一次）。
- **按需挂上**：只有画面挂上账本（`attachLedger(players)`）的游戏才记录。账本以玩家数组为键，所以大富豪模式五座城市（以及之后加入的大富翁城）共用一本。
- **存档**：`SaveData.stats` / `WorldSaveData.stats`，只在有账本时写入。旧存档没有这个字段，读入后画面开一本空账本，从读档那天起记。
- **观察点**：经典模式在 `Game.run()`（有账本时包一层 `observed`，原样转发每一步）；大富豪模式在 `World.toTicker()`，所有城市（画面上的和后台的）的事件都经过这里。每日统计在 `Game.dailySettlement` / `World.daily` 的日期加一之后。

## 2. 每名玩家的计数（`PlayerStats`）

| 字段 | 含义 | 来源 |
|---|---|---|
| `landsBought` / `landSpent` | 买下的普通地块数与花费 | `buy`(land)、拍卖得标（`auction` 的地块号 < 4000）、黑市买地、购地卡（`pay` 理由「購地卡」） |
| `plotsBought` / `plotSpent` | 买下的大型用地 | `buy`(facility)、拍卖得标的设施 |
| `buildings` / `buildSpent` | 付费盖房（地块或设施升一级）次数与花费 | `build` 且 cost > 0 |
| `levelsAdded` | 所有加盖的级数（付费 + 免费：福神、企业董事长加盖、机器工人、魔法屋） | `build`、`blessing`、`free-upgrade`、`robot-worker` |
| `facilitiesBuilt` | 在空地上建成的大型设施，按类型（0 公园、1 旅馆、2 购物中心、3 加油站、4 研究所、5..9 大富翁城五馆） | `build`(facility, level 1)，类型读当时的设施 |
| `tollsPaid` / `tollsReceived`（+`Count`） | 玩家之间的过路费与设施费：過路費、住宿費、購物費、加油費、賭場門票 | `pay`（双方都是玩家） |
| `sharesBought` / `stockBuyMoney` | 买入股数与金额（市场、认购、玩家间转让的买方） | `Stocks.addShares` |
| `sharesSold` / `stockSellMoney` / `stockProfit` | 卖出股数、到手金额、已实现获利 = 到手金额 − 卖出股份的平均成本 | `Stocks.sell`、`transferShares`（卖方）。违约交割、破产时卖股进奖池：到手 0，获利为 −成本 |
| `cardsBought` / `cardsUsed` | 买卡（商店、黑市）与用卡，按卡号 | 商店（`Tools.humanShop`/`aiShop`）、`black-market-buy`；`card` 减 `card-failed` |
| `toolsBought` / `toolsUsed` | 买道具（商店、黑市）与成功用道具，按道具号 | `Tools.buyTool`、`black-market-buy`；`Tools.use` 返回 true |
| `shopPoints` / `blackMarketSpent` | 商店花的点券、黑市花的现金 | 同上 |
| `lucky` / `unlucky` / `neutral`、`events` | 遇到的好事 / 坏事 / 中性事件，`events` 按来源键（`fate:20`、`news:8`、`local:<id>`、`god:1`、`object:mine`、`magic:2`、`lottery`）记 [好, 坏, 中] | 见 §3 |
| `gods` | 附身过的神明，按类型 | `god-attach` |
| `lotteryWins` / `lotteryPrize` | 乐透中奖次数与奖金 | `lottery-draw` |
| `miniGames` / `miniGamePoints` / `miniGameWins` | 小游戏（亲自玩或自动结算）场数、点券、得分场数 | `Places.miniGame` |
| `casinoGames` / `casinoWins` / `casinoNet` | 大富翁城赌场局数、赢的局数、净输赢 | `casino-result` |
| `hospitalDays` / `prisonDays` | 住院、坐牢的天数（每天开始时还在里面就加 1） | 每日 |
| `hospitalStays` / `prisonStays` | 新住院、新入狱次数（已在里面时加天数不算） | `to-hospital` / `to-prison` 的 `fresh` |
| `rivalsBankrupted` | 让对手破产的次数：破产前最后一笔付款付给了这名玩家 | `pay` → `bankrupt` |
| `bankruptDay` | 自己破产的那天（−1 = 没有） | `bankrupt` |
| `cities` / `trips` | 大富豪模式：到过的城市（含开局所在城市）、旅行抵达次数 | 每日、`travel-arrive` |
| `overlordCities` | 大富豪模式：曾经当过霸主的城市 | `World.checkOverlords` |
| `maxAssets` / `maxAssetsDay` | 最高总资产（02 §7.1 口径）与那天 | 每日、结束 |
| `maxLv5` | 同时拥有的 5 级建筑（5 级地块、满级设施）最多几栋 | 每日、结束 |
| `finalCash` / `finalBank` / `finalLoan` / `finalAssets` / `unrealized` | 结束时的现金、存款、贷款、总资产、未实现股票获利（Σ 股数 × 现价 − 股数 × 平均成本） | `ledger.finish()` |

读取接口（给结算画面与大富翁城筹码公式）：`ledgerOf(players)`、`ledger.of(p)`、`ledger.finish(game | world)`、`chipInputs(ledger, p)`（finalMoney、landsBought、levelsAdded、facilitiesBuilt、stockProfit、tollIncome、cardsUsed、toolsUsed、luckyEvents、unluckyEvents、citiesVisited、rivalsBankrupted、overlordCities、maxLv5、prisonDays）、`gameResults(g, winner)` / `worldResults(w, winner)`（排名后的结果）。

## 3. 好事、坏事的分类

一次新闻或命运的结果（`event-result`）对每个在结果行里出现的玩家各算一次：

1. 靠神明好运逃过（结果 `blessed`）→ 好事；
2. 否则看那一行的金额：收到钱 → 好事，付出钱 → 坏事；
3. 没有金额时用下表该条目的基调；结果行没有任何玩家时，命运算抽到的人，新闻（全市场类）不算任何人。

地方新闻与命运（18，大富豪模式）用条目自己的 `tone`（good / bad）。

## 4. 结算画面

所有模式结束时都显示（经典地图、大富翁城当经典地图玩、大富豪模式；大富翁城决战的 `finaleResults` 先显示，再进结算画面）：

- **冠军**：头像、皇冠、「X 获胜！」、地图名、天数、日期。人类输了时是「游戏结束」与人类的名次。大富豪模式用自己的领奖台或破产画面（`tycoon-ending.ts`）放在同一位置，并在统计下面附上资产走势、对手破产顺序、各城地产、去过的城市。
- **排名**：冠军第一，其余在场者按总资产，破产者按破产先后（越晚破产名次越前）。每行：名次奖牌、头像、名字、地产概况、总资产。点一行就在右侧（直屏在下方）显示那名玩家的统计。
- **统计**：总资产（最高）、现金＋存款、买地、盖房、大型设施、股票获利（未实现）、过路费收支、卡片 / 道具（用 / 买）、好事 / 坏事、打倒对手、住院 / 坐牢天数、乐透、小游戏、赌场；称号、去过的城市、附身神明、常用卡片与道具。
- **版面**：直屏 402×874 上下排列可滚动，横屏 874×402 左右两栏、按钮一行；按钮：「储存到相簿」「分享」「下一局」「回到主画面」。
- **图示**：每个统计格（与「称号」「去过的城市」等行）都带一个图示，22 个，同一风格（重绘道具图示那种亮面卡通立体小物件）：`tools/tycoon-art/stats_icons.py` 一次生成一整张 6×4 图（前两格放现有的机器娃娃、定时炸弹当风格参考），按连通块切成约 128 px 的透明 webp，放在 `editor/site/assets/remake/stats/<name>.webp`（`bundle-assets.mjs` 打包）；原图与图示备份在素材空间「大富翁4重制/結算圖示/」。
- **图片**：`results-card.ts` 用 canvas 画一张 1080 宽的直式图（同样的蓝底橘框紫边、标题牌只写「遊戲結算」、冠军、排名、所选玩家的 12 项统计及图示；大富豪模式另加去过城市、城市霸主、住院／坐牢三格），文字依当前简繁设定。App 中「储存到相簿」用 App 自带的 PhotoSaver 插件（iOS：`AppDelegate.swift`，`PHPhotoLibrary` 仅新增权限，Info.plist `NSPhotoLibraryAddUsageDescription`；Android：`PhotoSaverPlugin.java` 写入 `Pictures/大富翁4`，Android 9 以下要 `WRITE_EXTERNAL_STORAGE`），「分享」用 `@capacitor/filesystem` 写到缓存再以 `@capacitor/share` 打开系统分享面板；网页上储存是下载，分享用 `navigator.share`（不支持文件时改为下载）。

## 5. 下一局（对应原版的结束流程）

原版（01 §8.3，`csrc/main.c`、`fcn_004075c1`、`init_new_game`）：

- 单人获胜（结束码 2）：`fcn_004075c1` 把这张地图记为已通关（`0x4990f0[game_map] = 1`），显示该阶段的过关图（JUMP.MKF，已通关的地图盖章）；四张都通关时播放角色结局 `END%02d.AVI` 与 `THANKS.AVI`。没通关完时回到新游戏画面，`init_new_game(1)` 沿用上一局的人数、资金、行进方式、土地权限、游戏时间、胜利条件，并预选玩家的角色；对手要重新挑选，被打败的角色在角色表 `0x4990f4` 记为 2。
- 电脑获胜或人类破产：失败流程 `fcn_00407842` 问「再来一局」。

重制版：

- 「下一局」打开选图：8 张原版地图 + 自制地图（东京、大阪、札幌、九州、冲绳、大富翁城），本次连续游玩中通关过的地图盖「已通关」，刚玩过的盖「刚玩过」，默认选同一组里的下一张。
- 随机配 3 名电脑对手（人类保留自己的角色）：优先从本次还没被打败的角色中抽，不够时才用被打败的；可按「重新抽选」。
- 沿用这一局的设置：资金、行进方式、土地权限、游戏时间、胜利条件（大富豪模式之后的下一局沿用资金、行进方式、土地权限，时间与胜利条件为无限）。日期为今天，随机种子新取。
- 通关与打败的记录只在内存中（同原版的表），回到主画面就清空。
- 没有原版的过关图与结局动画（重制版没有这些资源的画面）。

## 6. 自制地图列表

自制地图只列重制版自己的 6 张（`maps/remake/index.json`）。旧的地图工坊地图（`maps/custom/index.json`，`editor/export_custom.py`）不再出现在新游戏与下一局的列表里，也不再打包进 App；它们仍以 `hidden` 列在地图表中，所以有它们的电脑上旧存档还能读取并显示地图名。
