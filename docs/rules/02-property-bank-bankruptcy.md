### 0.2 记号

- `PI` = 物价指数 `_rich4_price_index`（0x4990e8），整数，初始 1。
- `FUND` = 开局总资金 `_rich4_game_initial_fund`（0x49908c）。
- `trunc(x)` = 向零取整（代码中 `__round_toward_zero` + `fistp`）。所有整数除法也是向零截断（`idiv`）。
- `rand()` = C 库 `rand`，范围 0..32767（`RAND_MAX=0x7fff`，见下文 `fdiv 32767.0` 常量 `ref_00465014`）。`x % n` 用 `idiv` 余数。
  另外，每个游戏日开始时会用 `srand(GetTickCount())` 重新播种【代码确认】`rich4_player_core_actions.asm:4828–4831`（`fcn_0041cf67` 中）。重制版可用可注入的 PRNG。
- 地图引用号（节点 `+0x20`，`type_and_idx`）：`2001..3999` → 普通土地 `id = ref-2000`；`4001..5999` → 大型用地 `id = ref-4000`；`6001..7999` → 上市企业 `id = ref-6000`【代码确认】`rich4_player_core_actions.asm:365–380, 1086–1100, 1728–1740`。
- “玩家 id”从 0 开始；地产 `owner` 字段存 `id+1`，0 表示无主。
- 金额单位均为“元”，都是 32 位有符号整数。

## 1. 物价指数

【代码确认】`rich4_update_price_index.asm:11–49`（`_rich4_update_price_index` @0x423acf）

```
sum = 0; n = 0
for p in 所有玩家槽位: if who_plays[p] != 0: sum += wealth(p); n += 1
candidate = trunc(trunc(sum / n) / FUND)
if candidate > PI: PI = candidate        // 只升不降
```

- 初始值：新游戏时 `PI = 1`【代码确认】`rich4_new_game.asm:4201`。读档时从存档恢复（`rich4_player_save_state.asm:691`）。
- 调用时机：每个游戏日推进时调用一次（`fcn_0041cf67` → `rich4_player_core_actions.asm:4761`），在胜负判定之后、股票日处理之前【代码确认】。
- 含义：存活玩家的**平均总资产**每达到开局资金的整数倍，物价指数就升到该倍数（平均资产 < 2×FUND 时保持 1）。`wealth` 见 §7。
- 影响范围：几乎所有“元”金额都直接乘 `PI`：买地/加盖/建设、过路费、设施与企业费用、拍卖底价、交易市价、AI 资金保留线等（各节公式里写明）。**例外**：电脑费（§5）不乘 PI；拍卖加价档位（100/500/1000/5000/10000）不乘 PI。

### 3.3 过路费金额

【代码确认】`_rich4_calculate_land_toll`（0x419744）`rich4_player_core_actions.asm:229–296`；调用处 `:489–548`

```
calcToll(ownerPlus1, name):
  if name != null:   // 住宅
     s = Σ land.toll[land.level]  对所有 is_chain==0 && owner==ownerPlus1 && strcmp(land.name,name)==0 的土地
  else:              // 连锁店
     s = 2000 × (owner==ownerPlus1 且 is_chain!=0 的土地块数)
  return s * PI
```

停留在他人土地时：

```
base = is_chain ? calcToll(owner, null) : calcToll(owner, land.name)
allyPart = is_chain ? calcToll(ally, null) : calcToll(ally, land.name)   // ally = 地主的同盟对象（+65，id+1；0=无）
if land.tmp_state != 0: base *= 2                // 涨价；只翻倍地主部分
if ally != 0: total = base + allyPart; allyRatio = allyPart / total（float）
else total = base
```

要点：
- **“相邻/连片”不是按地图相邻，而是按路段名相同**：地主在同名路段拥有的所有非连锁土地，各自按自身等级取 `toll[level]`，全部加总后收取。踩到同路段任何一块都收这个总额。【代码确认】
- 空地（level 0）也收 `toll[0]`。【代码确认】
- 连锁店：地主名下**全图所有连锁店**块数 × 2000 × PI，与等级、地段无关，不与住宅合并。【代码确认】
- 同盟：地主的同盟伙伴在同路段（或连锁）的土地也并入总额，按比例分账（§3.7）。【代码确认】
- 收费前若同盟/同路段联动块数 > 1，会播放闪烁高亮（`fcn_00451985`），只是表现。【代码确认】`:550–661`

### 8.4 贷款

【代码确认】
- **额度**：进柜台时计算 `W = wealth(p)`（§7.1，`rich4_ui_bank.asm:3504`）。可借金额 = `W − 已有贷款`；已有贷款 ≥ W 时提示“金額已超過許可額度”（`:2022–2045, 2813–2836`）。即**累计贷款不能超过当前总资产**，与物价指数无关。台词“您的貸款額度為一百萬元”（`ref_00464880`）在代码中没有被引用，不是实际规则。
- **放款**：`bank += x; loan += x`（借来的钱进存款，不进现金）。
- **期限**：`fcn_00433b7e`（`:193–228`）：若尚无到期日（+44 == 0），到期日 = 今天 + 90 天；若该日是星期日或节假日（`fcn_004523d5`）就顺延一天，直到不是为止。**已有到期日时不改**，后续追加的贷款沿用第一笔的到期日。
- **利息**：**贷款不计息**（全代码无对 +36 的乘法写回）。代价是有贷款期间拿不到存款月息和新闻红利（§8.5）。
- **人类还款**：额度 ≤ 贷款；金额 > 现金+存款 时提示“您的現金不足”；**先扣存款再扣现金**；贷款还清时到期日清 0（`:2103–2125`）。
- **到期检查**：每个玩家回合开始（`fcn_0041c84f` → `fcn_00436a5a`，`rich4_ui_bank.asm:3787–3853`），`d = 到期日 − 今天`：
  - d = 3：人类弹出“您向銀行借貸的貸款即將到期 / 請不要忘記喔！”；
  - d = 2 / 1：“距貸款到期日還剩２天/１天！”；
  - d = 0：“貸款到期日強制執行！”：`fcn_00433bd8(p, loan)`，然后 `loan = 0`、到期日清 0。
- **强制扣款 `fcn_00433bd8`**（`:230–252`）：先扣存款；存款变负则用现金补；现金也变负则现金置 0 并**破产**。不变卖股票和地产。

### 10.4 流程

【代码确认】状态机 `ref_0048c4ac`：`:1315–1720`

1. 若无人入席 → “無人出價，宣佈流標”。否则提示“底價%d元 請意者出價”，从第一个入席者开始轮流。
2. 轮到某人：
   - 若当前价 > 他的现金 → 自动放弃（移出拍卖）。
   - 人类：选择加价档 100 / 500 / 1000 / 5000 / 10000（**固定金额，不乘 PI**，表 `ref_00475ba2`）、PASS 或放弃。新价超过自己现金则该按钮无效（`:539–545`）。
   - 电脑：见 §10.5。
   - PASS：本轮标记为已跳过；放弃：永久离席。
   - 有人成功加价：他成为最高出价者，并**清除所有入席者的标记**（`:699–712`）。
3. 每次轮转后统计：席上人数 `n`、带标记人数 `k`。`n == 0` 或 `n == k` → 流拍；`n == 1` 或 `n − k == 1`，且已有最高出价者 → 成交；否则轮到下一位。
4. 成交（`:3170–3260`）：若买家 ≠ 原 owner：原本无主且设置了土地權限 → 写新期限；`owner = 买家`。然后 `transfer(买家 → seller, 当前价, 0)`（seller=−1 时进乐透奖池；否则进卖方**存款**）。等级、连锁标志不变。
5. 流拍：地产状态不变（破产拍卖时已是无主；拍卖卡/魔法屋调用方另行把它设为无主）。

【推测·待实测】第 2 步“清除所有标记”会把卖方（7）、住院/坐牢等（1–6）、现金不足（8）的标记也清掉，代码上看这些人在有人出价后可能获得出价机会；电脑参与者若入席时不是标记 0，则心理上限为 0，只会 PASS。需实测卖方能否给自己的地出价。

### 10.5 电脑出价

【代码确认】心理上限 `fcn_00439f0d(bidderPlus1, ref)`，`rich4_ui_auction.asm:85–270`：

```
r = rand()/32767 × 0.3 + 0.5                        // [0.5, 0.8]
土地：
  same  = 该电脑在同名路段拥有的土地块数（不论是否连锁）
  free  = 全图无主土地块数
```

### 14.2 实现建议

1. **统一转账函数**：照 §9.1 实现 `transfer(from, to, amount, {payerBankFirst, toCash})`，破产在其内部触发并返回实际转出金额。默认收款进存款，这是原版行为，不要改成进现金。
2. **收费管线**：把“地主免收 → 金额计算 → 显示 → 付款人神明 → 免费卡/嫁祸卡 → 死神代付 → 同盟分账 → 转账 → 记录 lastToll”写成一条可复用的流水线，土地/设施共用，企业只用后半段（无地主免收）。
3. **数值**：所有乘法后立即 `Math.trunc`；`PI` 乘在最后（`calcToll` 是先求和再乘 PI）。浮点处（物价无、股票市值、拍卖 AI、同盟比例、新闻 ×1.3）用 `Math.fround` 模拟单精度可减少偏差。
4. **地价字段**：读原版地图时 +0x1c 是地价，+0x1e 是每级费，修正编辑器的命名。
5. **随机数**：所有 `rand()` 走一个可注入的 PRNG，范围 0..32767，便于回放和测试；原版每日用时间重新播种，重制版不必照抄。
6. **日处理顺序**（`fcn_0041cf67`，与本系统相关部分）：推进日期 → 已过天数+1 → 胜负判定 → 物价指数 → 公布栏挂牌天数 → 股票日处理 → 每月 15 日乐透开奖 → 若跨月：银行月结（存款 ×1.1，§8.5）→ 涨价/查封倒计时 → 产权到期。贷款到期、拒绝往来/暂停放款计数在**各玩家回合开始**处理（`fcn_0041c84f`），不在日处理里。
8. **银行**：贷款额度用实时总资产；到期日只在第一笔贷款时设置；利息只对“无贷款者”的存款按月 ×1.1 截断；特别融资要同时实现“准备金检查”和“易主收回”两个触发点，否则数值会与原版偏离。
7. **破产**：按 §9.3 顺序；拍卖 3 块用同一个 PRNG；股票卖出所得不会给任何人。
