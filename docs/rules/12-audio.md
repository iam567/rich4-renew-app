# 12 声音：音乐、音效与角色语音

> 适用版本：rich4.exe v3.11（与 `upstream/rich4` 一致）。
> 依据：`upstream/rich4/asm`（主要是 `rich4_media_music.asm`、`rich4_sound_effect.asm`、`csrc/media_init.c` 和各调用点），以及直接读 rich4.exe 数据段得到的表（槽位表、节日表、带 `#NNNN` 的字符串）。没有运行游戏。
> 路径缩写同 11：`rich4.asm:N`；其它 asm 文件写文件名（省略 `rich4_` 前缀）；`core` = `rich4_player_core_actions.asm`。`Effect#n` 是 Effect.mkf 第 n 项，`Voice#n` 是 Speaking.mkf 第 n 项。
> 提取：`scripts/extract_audio.py`（音效、语音、音乐 → `../rich4-audio`），`scripts/gen_voices.py`（语音对照表 → `game/src/ui/voices.ts`）。重制版的播放在 `game/src/ui/audio.ts`。

可信度标签：【代码确认】在反汇编中逐行读到；【数据确认】从 rich4.exe / MKF 直接读出；【推测·待实测】由代码结构或文件时长推断。

## 1. 音乐

### 1.1 播放机制（rich4_media_music.asm）【代码确认】

用 MCI 的 `sequencer` 设备（`open sequencer!%s alias mid`、`play mid from 0 notify`）。另有 CD 音轨模式（`0x47e770 = 1` 时播 `cdtrack`），v3.11 发行版不用，重制版忽略。

| 函数 | 作用 |
|---|---|
| `fcn_00454d91(n)` | 背景音乐：n ≠ 0 播第 n 首（`0x47e771 = n−1`），n = 0 播下一首（`(0x47e771+1)&7`）。状态 `0x47e772 = 序号 | 0x80` |
| `fcn_004549cf(i)` | 画面主题 MIDI(i)（表 `0x47e793`）。节日音乐计数 `0x46cb06 ≠ 0` 时**直接返回**；若当前是背景音乐且参数不带 0x8000，先 `fcn_00454b1a` 把背景曲号和播放位置压栈（`0x48cb70` / `0x48cb50`） |
| `fcn_00454bcc()` | 出栈：节日音乐时直接返回；否则从保存的位置（`play mid from %d notify`）续播那首背景音乐 |
| `fcn_00454acb()` | 停止（`close mid wait`） |
| `fcn_00454edc()` | 停止并清空栈 |
| `fcn_00454d2c()` | MCI 通知（窗口消息 0x3b9，`fcn_004544f6` 等待中也会转发）：背景音乐播完 → `fcn_00454d91(0)` 换下一首；主题 → `play mid from 0 notify` 从头循环 |
| `fcn_00454f5b()` | 当前背景曲号 + 1（选项画面高亮用） |

所以：**主题循环播放，背景音乐 8 首轮流**；循环点就是序列的最后一个事件（提取时按此剪切，`manifest.json` 记秒数）。

### 1.3 节日音乐（`fcn_00452444`、`fcn_0041cf67`）【代码确认 + 数据确认】

节日表 `0x47ff4a`（01 §4.4）效果位 4 的条目：

| 地图 | 日期 | 曲目（+10 字） | 天数 |
|---|---|---|---|
| 0 台湾、1 大陆 | 12/25 | 13 = MIDI14-1 | 1 |
| 0 台湾、1 大陆 | 农历 1/1 | 14 = MIDI14-2 | 3 |
| 2 日本、3 美国 | 12/25 | 13 = MIDI14-1 | 1 |

地图 4–7 没有节日音乐。命中时：若计数 `0x46cb06` 为 0，`fcn_00454edc` 停止清栈，`fcn_004549cf(曲目|0x8000)`；**下一条表项的 +10 不为 0** 时计数 = 0x33（3 天，农历 1/2、1/3 两条都写了 14），否则 0x11（1 天）。每日结算第 1 步（`fcn_0041cf67`）低 4 位减 1，到 0 时清零、停止、`fcn_00454d91(0)`。计数非 0 期间所有画面主题都不播（§1.1），节日歌一直响。时光机（tool_shiguangji.asm:40-56）把计数 +1，超过总天数就清零换回背景音乐。

同表的「画面」效果也有声音：1/1、10/10 等是 Data#523 烟火 + Effect#90，12/25 是 Data#554 圣诞老人 + Effect#114（`fcn_0045144f(res, 0, 40, 1, +8)`）。重制版还没有节日画面。

### 1.4 音量【代码确认】

RICH4.CFG +2 音乐 0–4（0 关）。`fcn_004545ba` 取 MIDI 设备当前音量 V，算出四档 `0x47e7e7..f3` = 0.6V、0.8V、0.9V、V（单声道设备为 0.7、0.8、0.9、1.0），`fcn_0045497b` 用 `midiOutSetVolume` 设定。0 档时 `fcn_004549cf` / `fcn_00454d91` 只记状态不播放。

## 2. 音效

### 2.1 播放机制（rich4_sound_effect.asm）【代码确认】

- **槽**：每个音效是 {Effect 号, DirectSound 缓冲} 一对，`−1` 结束成表。`_rich4_init_sound_effect_info(表)` 读入并登记（最多 16 张表），`fcn_00454240(表)` 释放。
- `_rich4_play_sound_effect(槽, flags)`：`SetCurrentPosition(0)` 再 `Play(0,0,flags)`，flags 1 = 循环；**同一个槽再播就从头重来，不同槽可以同时响**。音量 = 表 `0x47e758[cfg+3]`。
- `fcn_004542e9(槽)`：停止。
- 地图 FLC 的声音（`fcn_0045144f` 第 5 参数）：`fcn_00454304(号)` 临时载入一个缓冲，在**第 1 帧画完后**播放一次；flags bits 24–30 = N 时，第 N 帧再播 `fcn_00450cda` 登记的槽（只有掷骰和开局动画用）。
- 音量表 `0x47e758`（DirectSound 1/100 dB）：−10000、−2000、−1000、−500、0，对应 cfg+3 = 0..4；0 档什么都不播。

## 3. 语音

### 3.1 机制【代码确认】

所有经 `_rich4_draw_text`（text_drawing.asm:340-385）或 `_rich4_player_say`（rich4.asm:23660-23700）画出的字符串，若以 `#NNNN` 开头，就 `fcn_0045441a(NNNN)` 播放 **Speaking.mkf 第 NNNN 项**，然后跳过这 5 个字符再画正文。

- 同时只有一句（`0x47e750`）：新的一句先停掉旧的。
- 音量用**音效音量**（cfg+3），没有单独的语音音量。
- `fcn_004544f6(ms)`：等语音播完（期间左键/右键/按键会停掉语音并结束等待），再补足到 ms。对白云 1000 ms，新闻 2400 ms，讯息框按调用者。所以**对白云至少 1 秒，语音长就更久**。
