# 09 界面布局：主画面、面板、提示框与子画面

> 适用版本：rich4.exe v3.11（与 `upstream/rich4` 一致）。
> 依据：只用逆向资料（`upstream/rich4/asm`、`csrc`、`docs`）。素材核对用 `rich4-assets/manifest.json` 与各资源的帧图（本机提取的原版素材，只读），并按代码给出的坐标把帧图拼成整屏核对过。没有运行游戏。
> 路径缩写：`rich4.asm:N` 指 `upstream/rich4/asm/rich4.asm` 第 N 行；其它 asm 文件写文件名（省略 `rich4_` 前缀和目录）。`Data#N`、`map#N`、`Panel#N` 指 Data.mkf / map.mkf / Panel.mkf 的资源号（与 `rich4-assets/<包>/NNNN-*` 目录编号一致），`#N.f` 表示第 f 帧。
> 坐标一律是 640×480 屏幕像素。「画在 (x, y)」指把帧的**锚点**放到 (x, y)，即左上角 = (x − anchor_x, y − anchor_y)（见 §8.1）；锚点为 (0,0) 的帧就是左上角。
> 字符串是 BIG5 繁体原文，本文照录（含原版错字「點卷」）。

### 1.3 绘制顺序

【代码确认】主画面窗口过程 `fcn_00417e26`（rich4.asm:10373）的 WM_PAINT 分支（`loc_00418bb9`，rich4.asm:11421）：

1. 工具列 `fcn_00415d31`（rich4.asm:7590）。
2. 地图视图 `fcn_00415e70`（rich4.asm:7712）：调用 08 文档的 `fcn_0040829d(相机x, 相机y)`；相机 = 当前行动者坐标，或小地图「看别处」模式下的观察点（`0x48be18 ≠ 0` 时取 `0x48be1c/0x48be20`，§3.5）。
3. 右侧：
   - 视窗组 0：大面板 `fcn_00415f69`（rich4.asm:7811）→ 日历 `fcn_004169bc`（rich4.asm:8648）。
   - 视窗组 1：大面板 → 小地图 `fcn_00416e6d`（rich4.asm:9036）。
   - 视窗组 2：精简面板 `fcn_004166f8`（rich4.asm:8422）→ 小地图 → 日历。
4. GO 按钮 `fcn_00417191`（rich4.asm:9310）：**直接画在主表面上**，不进离屏缓冲；每块区域刷新到主表面后都会调用 `fcn_004174cd`（rich4.asm:9598），若刷新矩形与 GO 按钮矩形相交就重画 GO 按钮。所以 GO 按钮永远浮在最上层。

各块的离屏刷新矩形：工具列 (0,0)–(440,40)；地图 (0,40)–(440,480)；大面板 (440,0)–(640,280)；精简面板 (440,0)–(640,80)；小地图 (440,top)–(640,top+200)；日历 (440,280)–(640,480)【代码确认】。

各绘制函数的参数为 0 时只画进离屏缓冲、不上屏，并在 `0x475110` 里记脏位（bit0 工具列、bit1 地图、bit2 精简面板、bit3 y=80 的小地图/大面板、bit4 日历或 y=280 的小地图），整屏重画 `fcn_0041906a`（rich4.asm:11847）时一并上屏后清零。重制版可以忽略这层优化。

### 1.4 输入总闸

【代码确认】

- 主画面所有鼠标消息（按下、松开、移动、右键）开头都检查 `0x46cafd`，为 0 就直接忽略（rich4.asm:10618、11037、11188、11226）；热键钩子同样检查（keyboard_hook.asm `loc_004011df`）。
- `0x46cafd` 只由两处改动：`fcn_004196f1`（rich4.asm:12417）置 1 并显示 GO 按钮；`fcn_00419703`（rich4.asm:12426）清 0 并擦掉 GO 按钮。
- 置 1 的时机：回合状态机判定「轮到人类玩家、可以掷骰」（`loc_00418d99`，rich4.asm:11599），同时把鼠标指针移到 GO 按钮 (左+46, 上+34) 处；以及从工具列子画面返回且仍在等待掷骰时（ui_clicking_top_panel.asm:112-118）。
- 因此：电脑回合、移动中、讯息框显示中，工具列/分页/日历/小地图/地图点选**全部不响应**，画面上也没有任何变灰。重制版若要提示不可点，属于新增设计。
- **重制版的地图输入状态**（`BoardView.setMode`，`game/src/ui/board-view.ts`）照这个总闸：
  - `locked`（默认）：电脑行动、任何人移动、特效和讯息播放时。不能拖动、旋转地图，点地图不出资讯框，小地图不能「看别处」；镜头跟随当前行动者。点一下只用来跳过正在播的对话云、神明字幕（原版点击可提前结束）。
  - `free`：人类自己的回合、掷骰前（GO 显示中，`0x46cafd = 1`）：可拖动、旋转、点地图看资讯。按 GO 或进入任何子画面就回到 `locked`，镜头平滑回到人物身上。
  - `pick`：卡片、道具在画面内点选目标（05 §2.6，无 0x80）：只能点，地图不动。
  - `pick-scroll`：飞弹、核子飞弹（0x80）：可点，也可拖动、旋转去找目标。
- 防卡死（重制版）：画面上所有要等的动作（镜头移动、走一步、掷骰、特效、解码、语音）都有超时、被打断时也会结束；`game/src/ui/watchdog.ts` 在 15 秒没有进展（且不是在等人类）时把还在等的东西写进 console（`[watchdog]`，也可用 `__rich4.watch()` 查看），并让画面把手上的动作全部结束，游戏继续。

### 3.2 日视图（+12 = 0）

【代码确认】rich4.asm:8780-8938：

1. 背景：查当天节日 `fcn_004521f0(日期)`（01 文档 §4.4）。
   - 不是节日：Panel#2 第 `季节[月−1]` 帧，不透明画在 (440,280)。季节表 `0x475218` = `{3,0,0,0,1,1,1,2,2,2,3,3}`（1 月冬、2–4 月春、5–7 月夏、8–10 月秋、11–12 月冬）。【素材核对】#2.0 草地绿树 = 春，#2.1 海滩阳伞 = 夏，#2.2 红叶湖山 = 秋，#2.3 雪地木屋 = 冬。
   - 是节日（返回条目号 k）：载入 Data#(`0x475208[gmap]` + k)（200×200 RAW16 节日图）到缓冲，画在 (440,280)；`0x475208` = `{4, 28, 47, 67, 87, 108, 95, 118}`，下标 gmap = 阶段×4 + 地图号。同一张图连续两天不重复载入（`0x48bdd0` 缓存）。并标记「红字」。

### 8.2 字体

【代码确认】`_rich4_create_font(字号, 颜色, 颜色2, 样式, 字距)`（text_drawing.asm:242；C 还原 `csrc/font.c` `create_some_font`）：

- 字体名 `0x4660a0` = BIG5「細明體」（MingLiU），`CreateFontA(−字号, …, CHINESEBIG5_CHARSET)`：字号就是字符像素高（em 高），不是磅值。
- 样式：**恰好等于 2** 时为普通粗细（400），其它任何值都是粗体（700）；bit0 = 先在 (+1,+1) 用颜色2 画一层阴影；bit2 = 先在上下左右各偏 1 像素用颜色2 画四遍（描边），正文也右下移 1 像素。
- 字距：`SetTextCharacterExtra(字距 − 1)`，所以 1 = 正常，0 = 每字收紧 1 像素。
- 文字先画到一张临时表面，再**扫描非零像素求墨迹包围盒**，按包围盒对齐后贴上（`draw_some_text`）。对齐方式（`_rich4_draw_text` 第 5 参数）：

| align | 含义 |
|---|---|
| 0 | (x,y) = 墨迹左上角 |
| 1 | x = 墨迹右缘，y = 墨迹上缘 |
| 2 | 墨迹中心 = (x,y) |
| 3 | 竖排（每字一行，行距 = 字号 + 字距，样式 bit1/bit2 时再 +1），墨迹中心 = (x,y) |
| 4 | 多行，每行 DT_CENTER，整块墨迹中心 = (x,y) |
| 5 | x = 左缘，y = 墨迹垂直中心 |
| 6 | x = 右缘，y = 垂直中心 |
| 7 | x = 水平中心，y = 墨迹下缘 |

- 字符串以 `#NNNN` 开头时播放第 NNNN 句语音并跳过这 5 个字符。

**对重制版的意义**：同一坐标下，数字「1」和「8」的左上角位置不同（按墨迹）；要像素级一致，需要先量文字的实际墨迹再定位。用浏览器 `measureText` 的 `actualBoundingBox*` 可以近似。
