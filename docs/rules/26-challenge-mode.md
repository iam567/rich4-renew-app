# 26 挑戰模式（重制版新增，不是原版；设计稿 v0）

用户 2026-11-01：B 站有人拿重制版直播，想给直播出点东西。先想过「直播市區」地图（25，已暂停），然后想到：「整那種直播挑戰賽……最終輸贏不是把對手搞垮，不是讓對手破產，而是完成各種各樣奇奇怪怪的任務，就是賊難完成的那種任務」；「不要作為直播模式……我們不是有大富翁模式嗎？大富豪模式嗎？然後就有挑戰模式」。

所以：**第三种玩法「挑戰模式」**，和经典模式、大富豪模式并列。地图、角色、规则都用现成的，只多一个**任务**：完成任务才算赢。

本文是设计稿 v0，`game/` 还没改，数字和任务清单都是提案。

## 0 现状与下一步

- **状态（2026-11-01）**：设计稿 v0（本文），等用户挑任务、定 §2 的几条。
- 下一步：用 `core/ai-sim.ts` 的电脑对打模拟，每个候选任务跑几千局，量出「平均几局完成一次」（§4），用户看了数字再定清单和星数；然后才写规则（`game/src/core/challenge.ts`）和画面。

## 1 入口

- 新遊戲画面的地图区，三个页签变成四个：原版地圖、自製地圖、大富豪模式、**挑戰模式**。
- 挑战模式页签：先选**任务**（卡片一排，写名字、一句说明、难度星、你挑战过几次、最快几天完成），再选地图（经典模式能玩的地图都可以，个别任务限定地图）、人数 2–4、角色、电脑难度，和经典模式一样。
- 「隨機任務」按钮：转盘转一个任务出来（直播时请观众喊停）。
- 不进大富豪模式、派对模式（以后再说）。

## 2 输赢（提案，待用户确认）

1. **赢**：任务完成的那一刻，游戏停下，放庆祝画面，出一张**挑战成绩卡**（任务、地图、角色、用了几天、第几次挑战），可以截图。之后可以「結束」或「繼續玩完這局」（继续玩只是玩，不再计分）。
2. **输**：你破产。
3. **赢了游戏也算输**：对手全破产了、任务还没完成，画面写「你贏了遊戲，但挑戰失敗」。
4. **天数上限**：设定里可选「不限」（默认）或 1 年、2 年；到期没完成算失败。
5. 电脑**不知道**你的任务，照常打（想让你破产）；骰子、牌堆、转盘照常随机，**不作弊、不保底、不暗中帮忙**（公平随机原则）。电脑难度照经典模式的设定。
6. 任务只算**你自己**（人类 1P）；多个真人同局时各抽各的任务、先完成的人赢（待定）。

## 3 记录

- 每个任务记：挑战次数、完成次数、最快完成天数（本机保存，和统计账本 `core/stats.ts`、20 号文档放一起）。
- 画面角落常驻**任务进度条**，大字、直播画面也看得清：例「醫院 3/4」「現金 0 元：第 7 天」「打卡 9/14」。差一步时进度条闪一下。
- 存档存下任务和进度（新字段，读旧存档时当作没有任务；iOS 存档格式照 v0.7.3 不变）。
