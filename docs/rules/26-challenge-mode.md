# 26 挑戰模式（重制版新增，不是原版；设计稿 v1）

用户 2026-11-01：B 站有人拿重制版直播，想给直播出点东西。先想过「直播市區」地图（25，已暂停），然后想到：「整那種直播挑戰賽……最終輸贏不是把對手搞垮，不是讓對手破產，而是完成各種各樣奇奇怪怪的任務，就是賊難完成的那種任務」；「不要作為直播模式……我們不是有大富翁模式嗎？大富豪模式嗎？然後就有挑戰模式」。

接着定了计分（用户同日）：「扔三個骰子都是一樣的，扔出一次豹子算一顆星，三次算兩顆星，五次算三顆星；所有神明附過一次算一顆星，三次算兩顆星，五次算三顆星；最後統計誰的星多；金錢無限」。

所以：**第三种玩法「挑戰模式」**，和经典模式、大富豪模式并列。地图、角色、规则都用现成的，但**钱无限、没人破产**，大家比的是**星星**：做到各种奇葩的事就拿星，到期星最多的人赢。

本文是设计稿 v1，`game/` 还没改，数字和任务清单都是提案。

## 0 现状与下一步

- **状态（2026-11-01）**：设计稿 v1（本文），等用户挑任务、定 §2 的几条。
- 下一步：用 `core/ai-sim.ts` 的电脑对打模拟（钱无限），量出每个任务在一局（§2 的天数）里平均做到几次，再定每个任务的 1／3／5 次门槛合不合适、清单留哪些；用户看了数字再定，然后才写规则（`game/src/core/challenge.ts`）和画面。

## 1 入口

- 新遊戲画面的地图区，三个页签变成四个：原版地圖、自製地圖、大富豪模式、**挑戰模式**。
- 挑战模式页签：选地图（经典模式能玩的地图都可以）、人数 2–4、角色、电脑难度、**天数**（§2），和经典模式一样。
- 不进大富豪模式、派对模式（以后再说）。

## 2 规则

1. **钱无限**：每个人的现金显示「∞」，买地、盖房、付费、罚款、住院费都照扣照付但永远不会不够；没有破产，没有借款、存款（银行格照样是格子，进去没事可做）。股票照常可以买卖（钱无限，只是好玩）。
2. **计分：星星**。每个任务都按**做到的次数**给星，所有任务同一个门槛：

   | 做到 | 星 |
   |---|---|
   | 1 次 | ★ |
   | 3 次 | ★★ |
   | 5 次 | ★★★ |

   一个任务最多 3 颗星。每拿到一颗星，画面放一下特效、喊出任务名（直播效果）。
3. **所有人都拿星**，电脑也算（大多数任务靠运气，电脑照常玩也会碰到）。电脑不会特意去做任务（以后可以给「困难」电脑加）。
4. **结束**：玩到设定的天数（提案：3 个月／半年／1 年，默认半年），**星最多的人赢**；同样多时，先拿到最后那颗星的人赢。
5. 骰子、牌堆、转盘照常随机，**不作弊、不保底、不暗中帮忙**（公平随机原则）。
6. 存档存下各人的任务次数（新字段，读旧存档时当作经典模式；iOS 存档格式照 v0.7.3 不变）。

## 3 画面

- 右上角常驻**星星榜**：每人一行，头像＋星数，直播画面也看得清。
- 查询画面多一页「挑戰」：所有任务一张表，每人做到几次、几颗星；还差一次就升星的任务标出来。
- 结束时一张**成绩卡**（地图、天数、每人星数、拿星最多的任务），可以截图；本机记下最高星数。

## 5 实现要点（以后）

- `game/src/core/challenge.ts`：任务表（id、名字、说明、`count(g, p, event)`）；每天结束、每次掷骰／付费／住院／附身等事件后更新次数。只读游戏状态，不改规则、不碰随机流。
- 钱无限：现金扣到 0 以下时补回（不进破产判定），显示「∞」；电脑在挑战模式下买得起就买（原版的 AI 判断照用，钱永远够）。
- 统计账本已有大部分数字（20 号文档），缺的（连续天数、神明轮次等）在 challenge.ts 自己记。
- 画面：新遊戲的页签、星星榜、查询页、成绩卡（参考 `ui/results-card.ts`）。
